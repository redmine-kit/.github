# Security

This policy applies to the repositories of the [redmine-kit](https://github.com/redmine-kit) organization that have no security policy of their own.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the affected repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue, discussion or pull request for a vulnerability.

Include:

- the repository and the version or commit,
- the Redmine version, if it matters,
- the steps to reproduce,
- what an attacker could do.

We reply through the report and keep you informed while we work on a fix.

## Supported versions

Fixes go into the latest release of each project. Several projects are still in the design stage and have no releases; reports about their designs are welcome through the same channel.

## Scope

redmine-kit is not affiliated with the Redmine project. Report vulnerabilities in Redmine itself to the Redmine project ([Security Advisories](https://www.redmine.org/projects/redmine/wiki/Security_Advisories)).

## 脆弱性の報告(日本語)

脆弱性は、GitHub で非公開で報告してください。該当するリポジトリの **Security** のタブを開き、**Report a vulnerability** を選びます。公開の Issue、Discussion、プル リクエストでは報告しないでください。Redmine 本体の脆弱性は、Redmine のプロジェクトに報告してください。
