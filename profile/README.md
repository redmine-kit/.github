# Redmine Kit

Open-source tools for [Redmine](https://www.redmine.org/). Not affiliated with the Redmine project.

## Plugins

| Plugin | What it is |
| --- | --- |
| [redmine_lookbook](https://github.com/redmine-kit/redmine_lookbook) | Redmine Lookbook: previews of Redmine 7's components and pages in Lookbook, for theme authors |
| [redmine_serverless](https://github.com/redmine-kit/redmine_serverless) | Redmine Serverless: runs Redmine on AWS serverless services (design stage) |
| [redmine_github](https://github.com/redmine-kit/redmine_github) | Connects GitHub repositories through a GitHub App (under consideration) |

## Other projects

| Project | What it is |
| --- | --- |
| [serverless](https://github.com/redmine-kit/serverless) | A design for running the latest Redmine on AWS Lambda with S3 |
| [docs-skeleton](https://github.com/redmine-kit/docs-skeleton) | The VitePress skeleton of the documentation sites |
