# redmine-kit

Open-source tools for [Redmine](https://www.redmine.org/). Not affiliated with the Redmine project.

| Project | What it is |
| --- | --- |
| [redmine_lookbook](https://github.com/redmine-kit/redmine_lookbook) | Previews of Redmine 7's components and pages in Lookbook, for theme authors |
| [redmine-serverless](https://github.com/redmine-kit/redmine-serverless) | A design for running the latest Redmine on AWS Lambda with S3 |
| [redmine_serverless](https://github.com/redmine-kit/redmine_serverless) | Redmine Serverless, the plugin of redmine-serverless |
| [redmine_github](https://github.com/redmine-kit/redmine_github) | A Redmine plugin that connects GitHub repositories through a GitHub App |
| [docs-skeleton](https://github.com/redmine-kit/docs-skeleton) | The VitePress skeleton of the documentation sites |

Documentation: https://redmine-kit.github.io/ (日本語: https://redmine-kit.github.io/ja/)
